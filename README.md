# PulseAPI - SaaS Landing Page

A responsive, interactive SaaS landing page built for the **Sankar Group Front-End Development Internship** assignment.

PulseAPI is a conceptual uptime monitoring platform designed for developers and backend teams. The landing page focuses on API reliability, monitoring, alerts, and a simple SaaS conversion experience using a modern dark-mode interface.

[**PulseAPI Live Website**](https://pulseapi-landing.vercel.app/)

## 📂 GitHub Repository

[**PulseAPI GitHub Repository**](https://github.com/pardhavkrishna21/pulseapi-landing)

## 🛠️ Technologies Used

- **Framework:** React (via Vite)
- **Routing:** React Router DOM
- **Styling:** Pure CSS
- **Layout:** CSS Flexbox, CSS Grid, Media Queries
- **Icons/Visuals:** CSS and HTML symbols
- **State Management:** React `useState`
- **Deployment:** Vercel

## ✨ Key Features

- **Responsive Navigation:** Desktop navigation with a mobile hamburger menu.
- **Dual Navigation System:** Combines URL routing with smooth on-page section navigation.
- **Hero Section:** Includes product messaging, CTA buttons, and an interactive API monitoring dashboard.
- **Interactive Hero Dashboard:** Simulates API endpoint monitoring and randomized latency responses using React state.
- **Core Features Section:** Highlights global API checks, instant alerts, and API monitoring capabilities.
- **How It Works Section:** Explains the basic PulseAPI monitoring workflow.
- **Pricing Section:** Includes multiple pricing plans and interactive pricing elements.
- **Signup & Demo Forms:** Client-side form validation with success-state feedback.
- **Contact Section:** Provides support information and demo request functionality.
- **Responsive Layout:** Adapts the interface for desktop, tablet, and mobile screen sizes.

## 🎨 Design & Implementation

PulseAPI was designed with a modern dark SaaS interface to give the product a professional developer-focused appearance.
I used React and Vite to create reusable and maintainable UI components.
Pure CSS with Flexbox, Grid, CSS variables, and media queries was used to build the responsive layout.
The interactive monitoring dashboard uses React state to simulate endpoint latency and status changes.
Smooth navigation and routing were implemented to make movement between product sections simple.
The main challenge was maintaining consistent spacing, typography, and component layout across different screen sizes.
I also implemented client-side validation and success feedback for the signup and demo request interactions.

## ⚙️ Local Setup Instructions

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/pardhavkrishna21/pulseapi-landing.git
```

### 2. Navigate to the project

```bash
cd pulseapi-landing
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available on the local Vite development URL shown in the terminal.
